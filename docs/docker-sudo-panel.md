# Solicitud de sudo en el panel Docker

Cuando Docker solicita una contraseña de sudo, el diálogo ocupa solo el área de
contenido de Docker en el panel inferior de la sesión que la pidió. La barra de
pestañas, sus controles y la terminal siguen disponibles con el ratón y el
teclado. Si se oculta el panel o se cambia de pestaña, el diálogo se oculta y se
descarta el texto ingresado.
