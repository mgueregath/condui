# Atajos del terminal

Referencia de atajos habituales en emuladores de terminal. Su inclusión en esta lista no implica que todos estén implementados actualmente en Condui.

## Portapapeles

| Acción | Windows/Linux | macOS |
| --- | --- | --- |
| Copiar selección | `Ctrl+Shift+C` | `Command+C` |
| Pegar | `Ctrl+Shift+V` | `Command+V` |
| Seleccionar todo | `Ctrl+Shift+A` | `Command+A` |

## Pestañas y sesiones

| Acción | Windows/Linux | macOS |
| --- | --- | --- |
| Nueva pestaña | `Ctrl+Shift+T` | `Command+T` |
| Cerrar pestaña | `Ctrl+Shift+W` | `Command+W` |
| Pestaña siguiente | `Ctrl+Tab` | `Control+Tab` |
| Pestaña anterior | `Ctrl+Shift+Tab` | `Control+Shift+Tab` |
| Ir a la pestaña 1-9 | `Alt+1` … `Alt+9` | `Command+1` … `Command+9` |
| Mover pestaña | `Ctrl+Shift+PageUp/PageDown` | `Command+Shift+←/→` |
| Nueva ventana o sesión | `Ctrl+Shift+N` | `Command+N` |

## Visualización y navegación

| Acción | Windows/Linux | macOS |
| --- | --- | --- |
| Aumentar fuente | `Ctrl++` | `Command++` |
| Reducir fuente | `Ctrl+-` | `Command+-` |
| Restablecer fuente | `Ctrl+0` | `Command+0` |
| Buscar texto | `Ctrl+Shift+F` | `Command+F` |
| Historial anterior/siguiente | `Shift+PageUp/PageDown` | `Shift+PageUp/PageDown` |
| Pantalla completa | `F11` | `Control+Command+F` |
| Limpiar pantalla | `Ctrl+L` | `Ctrl+L` |

## Atajos reservados para el shell

Estos atajos deben enviarse al proceso activo y no utilizarse como acciones de la interfaz:

| Atajo | Uso habitual |
| --- | --- |
| `Ctrl+C` | Interrumpir el proceso activo |
| `Ctrl+Z` | Suspender el proceso activo |
| `Ctrl+D` | Enviar fin de entrada o cerrar el shell |
| `Ctrl+\\` | Finalizar el proceso y generar un volcado, si está habilitado |

> Algunos atajos pueden variar según el sistema operativo, el shell o la configuración del usuario.
